# Security Policy

## Supported Versions

Currently, the following versions of Ariba Shield WAF are actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Security is a core value of Ariba Shield WAF. If you discover a vulnerability or a potential security issue in this project, we kindly ask you **NOT** to open a public issue on GitHub. 

Instead, please report it privately:

1. Send an email to **boniyeamin.cse1@gmail.com**.
2. Include a detailed description of the vulnerability.
3. Provide step-by-step instructions to reproduce the issue (PoC).
4. Do not disclose the vulnerability in public forums until we have successfully patched it and released a fix.

### Response Time

- You can expect an initial acknowledgment of your report within 48 hours.
- We will prioritize addressing the vulnerability and communicate a timeline for a patch.
- We will credit you (if you wish) in the release notes when the security advisory is published.

Thank you for helping keep Ariba Shield and its users safe!
