1. Introduction

Welcome to Ariba Shield WAF, an enterprise-grade Web Application Firewall designed to protect your infrastructure from malicious traffic, zero-day exploits, and OWASP Top 10 vulnerabilities.

This guide will walk you through accessing the dashboard, monitoring traffic, and managing your security settings.

2. Accessing the Dashboard

To access the Ariba Shield Control Console, open your web browser and navigate to the application's URL. If you are running this locally on your network, you can use your machine's IP address.

http://localhost:3000/
or
http://<your-local-ip>:3000/ (e.g., http://10.24.50.129:3000/)

Default Credentials:

  • Email: superadmin@aribashield.local
  • Password: admin

* Ensure you change these credentials in your production .env file.

3. Dashboard Overview

Once logged in, you will be greeted by the Overview Dashboard. This provides a real-time, birds-eye view of your network's security posture.

  • Top Metrics: Instantly view total incoming requests, blocked threats, and active gateways.
  • Traffic Flow: A visual graph representing traffic spikes and mitigated attacks over time.
  • Top Client IPs: Identifies the source IPs generating the most traffic or suspicious behavior.
  • Top Triggered Rules: Shows which WAF rules (e.g., SQL Injection, XSS) are intercepting the most traffic.

4. Core Features & Navigation

Use the left-hand sidebar to navigate through the core components of the Web Application Firewall.

Security Policies

Define how the WAF treats incoming traffic. You can enable or disable specific OWASP core rule sets, configure custom blocklists, and manage rate limiting.

Monitoring Security Events

This page provides a detailed ledger of every blocked request. Click on an event to see deep insights, including the exact payload that triggered the block, the user agent, and the corresponding WAF rule ID.

Analytics Reports

Generate, view, and download comprehensive security reports.

  1. Navigate to the Reports tab.
  2. View the list of previously generated reports.
  3. Click the Download icon next to a report to save it locally as a PDF or CSV for compliance auditing.

5. System Settings

The Settings page allows administrators to configure global application behaviors. It is divided into four categories:

Category Description
General Manage the site name, admin contact email, and toggle Maintenance Mode.
Security Configure session timeouts, maximum login attempts, and enforce Multi-Factor Authentication (MFA).
Localization Set the default language (English/Bengali) and system timezone.
Retention Define how many days Audit Logs and Security Events are kept in the database before automatic deletion.

After making changes, click Save Changes. Configurations take effect immediately across all active sessions.

6. Troubleshooting

API Offline Error

If the dashboard displays an "API Offline" badge, the frontend is unable to reach the backend control API. Ensure that:

  • The Docker containers are running (docker compose ps).
  • You are not blocked by a local firewall.
  • The NEXT_PUBLIC_API_BASE is correctly routing to your IP.

Changes Not Saving

If settings fail to save, ensure your database container (postgres) is healthy and that you have sufficient permissions.
